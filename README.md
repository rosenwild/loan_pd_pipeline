## 📌 Описание проекта

Проект направлен на создание **сквозного ML-пайплайна** (end-to-end) для решения задачи **бинарной классификации**.  
Цель — реализовать воспроизводимый процесс от загрузки данных и предобработки до обучения и оценки моделей, с элементами автоматизации (MLOps).

## 📊 Данные
- Название: Loan Default Prediction Dataset
- Источник: [Kaggle](https://www.kaggle.com/datasets/nikhil1e9/loan-default)
- Объем: более 255 тысяч записей  
- Целевая переменная: Default (Флаг выхода в дефолт (0/1))
- Краткое описание признаков (включая новые признаки после preprocessing):
  | Признак                | Описание                                                                                           |
  | ---------------------- | -------------------------------------------------------------------------------------------------- |
  | **LoanAmount**         | Сумма кредита, запрошенная клиентом                                                                |
  | **Income**             | Ежемесячный доход заёмщика                                                                         |
  | **CreditScore**        | Кредитный рейтинг клиента                                                                          |
  | **Age**                | Возраст заёмщика                                                                                   |
  | **HasMortgage**        | Наличие ипотеки (`Yes` → 1, `No` → 0)                                                              |
  | **HasDependents**      | Наличие иждивенцев (`Yes` → 1, `No` → 0)                                                           |
  | **HasCoSigner**        | Наличие поручителя (`Yes` → 1, `No` → 0)                                                           |
  | **Education**          | Уровень образования (строковое значение)                                                           |
  | **Education_ord**      | Уровень образования (числовое значение: `High School`→1, `Bachelor’s`→2, `Master’s`→3, `PhD`→4)    |
  | **EmploymentType**     | Тип занятости (строковое значение)                                                                 |
  | **EmploymentType_ord** | Тип занятости (числовое значение: `Part-time`→1, `Unemployed`→2, `Self-employed`→3, `Full-time`→4) |
  | **MaritalStatus**      | Семейное положение (строковое значение)                                                            |
  | **MaritalStatus_ord**  | Семейное положение (числовое значение: `Married`→1, `Divorced`→2, `Single`→3)                      |
  | **LoanPurpose**        | Цель кредита (строковое значение)                                                                  |
  | **LoanPurpose_ord**    | Цель кредита (числовое значение: `Business`→1, `Home`→2, `Education`→3, `Auto`→4, `Other`→5)       |
  | **loan_to_income**     | Отношение суммы кредита к доходу заёмщика                                                          |
  | **Default**            | Целевая переменная: факт дефолта по кредиту (`1` — дефолт, `0` — нет)                              |

## 🚀 Запуск проекта

### 1. Клонировать репозиторий
```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
```

### 2. Создать окружение и установить зависимости
```bash
python -m venv .venv
source .venv/bin/activate  # или .venv\Scripts\activate (Windows)
pip install -r requirements.txt
```

### 3. Загрузить данные (через DVC)
```bash
dvc pull
```

### 4. Запустить пайплайн
```bash
python src/train.py
```

### 5. Запустить тесты и линтеры
```bash
pytest -v
flake8 src tests
```
